About

I started in IT as the administrator for two gaming lounges, automating installs, updates and monitoring across 20+ machines and keeping their networks up. Today I run a Linux server at home with more than 25 containers: Pi-hole DNS filtering, a reverse proxy with SSL, Tailscale for remote access, a Jellyfin media pipeline, and test deployments of my clients' websites. I also handle the domain, DNS and staff devices for a wellness practice whose booking system I built.

When the tools I need don't exist, I build them. Gaming cafes like the ones I used to run needed a way to lock PCs and switch off TVs when paid time ends, so I wrote Cafe Manager: a Windows-service server, a lock agent on every PC and Wake-on-LAN control of the TVs. My Mac had no good system-wide equalizer, so I wrote one in Rust on Core Audio process taps. My consoles sat by the TV, so I wrote a capture-card streamer with a Linux service at one end and a native Mac app at the other.

I like the parts of software that sit near hardware and networks: Linux services, USB and serial devices, LAN protocols, and the native layers on Windows, macOS and Android. I also build web apps when a problem calls for one, from a booking site to an online gift shop.

In the age of AI, I believe what matters is what you complete and ship, and how well you ship it. Anyone can start something now. Finishing it, polishing it and putting it in someone's hands is the part that counts.

So each project ships with releases, screenshots in both themes and documentation that explains how the thing works, not just how to install it.

Self-hosted home server

An Ubuntu Server box running 25+ containers with Docker Compose and Portainer, including test deployments of my clients' websites. A fully automated media pipeline takes a request through download and subtitle fixing into the Jellyfin library. Pi-hole filters DNS for the whole network, Nginx Proxy Manager serves internal apps on public domains with SSL, and Tailscale connects it all. I also tracked down and closed an IPv6 DNS leak through the router's RADVD and DHCPv6 settings.

Cafe Manager

Management software for a small gaming cafe that runs on one server in the cafe, with no internet needed. Staff start timed sessions from a browser; a lock agent on each Windows PC unlocks for the session and locks again when time runs out, and Samsung TVs power off at expiry. POS with receipts, customer balances, reports, nightly backups and PowerShell installers. Released as v1.0; not yet in use at a cafe.

EQ for macOS

A free system-wide parametric equalizer for every sound your Mac plays. No audio driver, no kernel extension, no account. Drag points on a frequency-response curve and hear the change at once, run a frequency sweep to find where your speakers ring, and compare settings with a volume-matched A/B.

capture-stream

Play a PS4, PS5, Switch or Xbox from another room. A USB capture card on a Linux box forwards MJPEG frames unchanged to a native Mac app that decodes them in hardware, with optional MetalFX upscaling. About 12 ms of video delay at 720p60, and a controller connected to the Mac can drive a PS4 over WebRTC.

JA11 EQ

A small macOS app that programs the on-board five-band parametric EQ of the FiiO JadeAudio JA11 USB DAC dongle over USB. The curve lives in the dongle, so it follows you to a phone or another computer. It replaces FiiO's own configuration app on the Mac.
